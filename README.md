Les variables $note et $Note sont différentes car PHP est sensible à la casse. 
Les majuscules et les minuscules sont donc distinguées.

`$a`: valide
`$_a` : valide
`$a_a` : valide
`$AAA` : valide
`$a!` : invalide
`$1a` : invalide
`$a1` : valide
